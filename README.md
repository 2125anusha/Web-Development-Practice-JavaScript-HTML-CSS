# 🚀 Web Development & Coding Practice

This repository contains Responsive web design related practice workshops and labs, exercises, challenges and mini projects.

## 📚 Platforms Covered

*   **freeCodeCamp:** Responsive Web Design, JavaScript certification challenges, [My Profile](https://www.freecodecamp.org/anusha-2125)
*   **Udemy:** Hands-on projects from the course: ['The Complete Full-Stack Web Development Bootcamp, by Angela Yu'](https://www.udemy.com/course/the-complete-web-development-bootcamp/)
*   **Coddy.tech:** Bite-sized coding challenges, [My Profile](https://coddy.tech/user/2125anusha)
*   **SoloLearn:** Language Basics, Core concept quizzes, [My Profile](https://www.sololearn.com/en/profile/37731512)

## 📁 Repository Structure

The folder structure is organized by platform and topic of course:
```text
├── freecodecamp/       # Certification courses and additional challenges
├── udemy/              # Code-along projects
└── coddy-tech/         # Daily challenges
```
